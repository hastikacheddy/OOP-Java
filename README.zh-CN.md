# OOP-Java · Java 面向对象编程练习

[English](README.md) | 简体中文

本仓库收录了我在 **面向对象软件开发（OOSD）** 课程中完成的 Java 练习答案，涵盖类与对象、封装、方法、数组等面向对象编程基础知识。

## 项目结构

| 路径 | 说明 |
| --- | --- |
| `OOP/Labsheet2`、`OOP/Labsheet 2 b` | 实验 2：基础语法、数学运算、密码校验、数组等练习 |
| `OOP/Labsheet 3a`、`OOP/Labsheet 3b` | 实验 3：类的设计，如 `Book`、`Circle`、`Employee`、`Invoice`、`Pizza` 等 |
| `OOP/ClassworkWork2021` | 2021 年课堂练习，如工资库 `PayrollLibrary`、交通工具 `Vehicle` |
| `WelcomeApplication.java`、`labsheet1q2.java` | 入门练习 |
| `JavaCheat.md` | Java 常用语法速查表 |

## 运行方法

需要安装 JDK 8 或更高版本：

```bash
javac WelcomeApplication.java
java WelcomeApplication
```

其他练习同理，进入对应目录后编译并运行包含 `main` 方法的类即可。
